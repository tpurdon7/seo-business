# Client onboarding checklist

Owner: `[name]`  
Client: `[client]`  
Package: `[package]`  
Target start: `[date]`

## Gate 1 — Sale complete

- [ ] Proposal approved.
- [ ] Correct legal entity and billing details recorded.
- [ ] SOW/agreement signed.
- [ ] Initial invoice paid or payment mandate active.
- [ ] Package, limits, start date and VAT treatment confirmed.
- [ ] Pipeline marked Won.
- [ ] Delivery owner assigned.

Do not start delivery before this gate unless an authorised exception is documented.

## Gate 2 — Welcome and workspace

- [ ] Send welcome email within one working day.
- [ ] Introduce delivery contact.
- [ ] Create client folder/project workspace.
- [ ] Save signed scope and proposal.
- [ ] Add delivery milestones and recurring tasks.
- [ ] Confirm communication channel and response expectations.
- [ ] Book kick-off call.
- [ ] Send intake form and access instructions.

## Gate 3 — Intake complete

- [ ] Business goals and priority services confirmed.
- [ ] Priority locations/customer groups confirmed.
- [ ] Baseline commercial and enquiry context recorded.
- [ ] Competitors recorded.
- [ ] Brand, legal and regulated-content requirements received.
- [ ] Decision-maker and approvers named.
- [ ] Known redesign, migration or campaign plans recorded.
- [ ] Existing agency/developer responsibilities clarified.

## Gate 4 — Secure access

Request only what is necessary.

- [ ] Website CMS — named user with suitable permissions.
- [ ] Google Search Console — delegated user access.
- [ ] GA4 — read/analyse access.
- [ ] Google Tag Manager — read or publish access as required.
- [ ] Google Business Profile — manager access if in scope.
- [ ] Hosting/developer contact — only if required.
- [ ] Rank tracking or existing SEO tools — if relevant.
- [ ] Booking/CRM conversion data — read-only if relevant and lawful.
- [ ] Access tested.
- [ ] Unnecessary access declined or removed.

Never request passwords by email. Record who has access and schedule removal at offboarding.

## Kick-off agenda — 45–60 minutes

- [ ] Reconfirm desired outcome and scope.
- [ ] Confirm priority services, pages and locations.
- [ ] Review customer decision journey and common questions.
- [ ] Confirm proof, qualifications and claims that may be used.
- [ ] Confirm prohibited or approval-sensitive language.
- [ ] Review analytics quality and known website issues.
- [ ] Confirm responsibilities and approval turnaround.
- [ ] Review first 30-day plan.
- [ ] Confirm next meeting/report date.

## First 30-day setup

### All packages

- [ ] Save baseline screenshots/exports where appropriate.
- [ ] Confirm crawl/indexing status.
- [ ] Confirm tracking limitations.
- [ ] Create issues/opportunities backlog.
- [ ] Record dependencies and risks.

### Visibility Sprint

- [ ] Confirm audit URL limit and competitors.
- [ ] Complete research plan.
- [ ] Schedule findings call.

### Retainers

- [ ] Create 90-day roadmap.
- [ ] Select first month’s work items.
- [ ] Confirm implementation route.
- [ ] Set monthly reporting date.
- [ ] Set recurring strategy call.
